# 픽셀 스냅퍼 · Windows

[최신 버전 받기](https://github.com/JIINNY-Hee/spritefusion-pixel-snapper/releases/latest/download/PixelSnapper.exe)

Windows 10/11 64비트용 한국어 데스크톱 앱입니다. `PixelSnapper.exe` 하나를 내려받아 더블클릭하면 됩니다. 변환 엔진과 .NET 실행 환경이 포함되어 있어 별도 설치가 필요 없습니다.

## 이미지 변환

1. 이미지 파일을 창에 끌어놓거나 **파일 추가**를 누릅니다.
2. 색상 수와 저장 위치를 선택합니다. 기본 색상 수는 16입니다.
3. **변환 시작**을 누르고 원본과 결과를 비교합니다.

- PNG / JPG / JPEG 여러 파일을 한 번에 변환합니다.
- 폴더 추가는 선택한 폴더 바로 안의 이미지를 불러옵니다. 하위 폴더는 제외합니다.
- 결과는 PNG로 저장합니다. 원본과 기존 결과는 덮어쓰지 않으며 같은 이름이 있으면 번호를 붙입니다.
- 픽셀 격자를 자동 감지하므로 결과 해상도가 원본과 달라질 수 있습니다.
- 미리보기는 최대 800%로 확대할 수 있습니다. 큰 이미지는 미리보기만 축소하며 변환에는 원본을 사용합니다.
- 이미지는 이 컴퓨터에서 처리합니다. 이미지 파일을 서버로 업로드하지 않습니다.

## 업데이트

기본 설정에서는 앱을 시작할 때 이 저장소의 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 앱에서 알려주며, 사용자가 업데이트를 선택하면 다운로드·검증·실행파일 교체 후 다시 시작합니다. 수동으로 업데이트를 확인할 수도 있고, 시작 시 자동 확인은 끌 수 있습니다.

업데이트에는 인터넷 연결과 실행파일이 저장된 폴더의 쓰기 권한이 필요합니다. 연결이 없거나 확인에 실패해도 기존 이미지 변환 기능을 사용할 수 있습니다. 다운로드한 실행파일은 릴리스의 SHA-256 체크섬과 대조하며, 이전 실행파일은 교체 중 복구를 위해 백업합니다.

기존 1.0.0에는 업데이트 기능이 없으므로 **1.1.0 이상을 한 번 직접 받아 교체**해야 합니다. 그 이후 배포되는 새 버전부터 앱 안에서 업데이트할 수 있습니다.

설정·변환 엔진·업데이트 임시 파일은 `%LOCALAPPDATA%\PixelSnapper` 아래에 저장됩니다. 이 폴더는 처음 사용할 때 자동으로 만들어집니다.
