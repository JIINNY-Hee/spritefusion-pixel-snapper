# 픽셀 스냅퍼 · Windows

[최신 버전 받기](https://github.com/JIINNY-Hee/spritefusion-pixel-snapper/releases/latest/download/PixelSnapper.exe)

Windows 10/11 64비트용 한국어 데스크톱 앱입니다. `PixelSnapper.exe` 하나를 내려받아 더블클릭하면 됩니다. 변환 엔진과 .NET 실행 환경이 포함되어 있어 별도 설치가 필요 없습니다.

## 이미지 변환

1. 이미지 파일을 창에 끌어놓거나 **파일 추가**를 누릅니다. 선택한 이미지의 변환 결과가 자동으로 미리보기에 표시됩니다.
2. 색상 수와 세밀도를 조절하며 원본과 결과를 비교합니다. 기본값은 16색과 세밀도 **자동**입니다.
3. 원하는 결과 해상도가 있으면 **출력 크기 지정**을 켜고 **가로·세로(px)**를 입력합니다. 옵션을 바꾸면 미리보기도 자동으로 갱신됩니다.
4. 저장 위치를 선택하고 **변환 시작**을 누르면 목록의 이미지들을 현재 옵션으로 변환하여 PNG 파일로 저장합니다.

- PNG / JPG / JPEG 여러 파일을 한 번에 변환합니다.
- 미리보기는 목록에서 **선택한 이미지**를 대상으로 합니다. 다른 이미지를 클릭하면 해당 이미지의 결과를 보여줍니다.
- 색상 수, 세밀도의 자동·직접 지정과 값, 출력 크기, 가로·세로 및 체인 연결을 바꾸면 미리보기를 갱신합니다. 숫자를 입력할 때는 잠시 입력을 멈춘 뒤 마지막 옵션을 적용합니다.
- **미리보기만으로 결과 파일이 저장되지는 않습니다.** 결과 PNG는 **변환 시작**을 눌렀을 때만 저장합니다. 미리보기용 임시 데이터는 별도로 처리하고 정리하므로 원본 옆이나 지정한 저장 폴더에 결과가 쌓이지 않습니다.
- 저장한 뒤 옵션을 바꾸면 미리보기만 달라집니다. 변경한 옵션으로 결과 파일을 만들려면 **변환 시작**을 다시 누르세요.
- 폴더 추가는 선택한 폴더 바로 안의 이미지를 불러옵니다. 하위 폴더는 제외합니다.
- 이미지 목록에서 이미지를 클릭한 뒤 **Delete** 키를 누르면 선택한 항목을 목록에서 제외합니다. 원본 파일은 삭제하지 않습니다.
- 결과는 PNG로 저장합니다. 원본과 기존 결과는 덮어쓰지 않으며 같은 이름이 있으면 번호를 붙입니다.
- **출력 크기**는 저장되는 PNG의 실제 가로·세로 픽셀 수입니다. 체인을 연결하면 원본 이미지 비율을 유지하고, 가로 또는 세로를 수정하면 반대쪽 값이 자동으로 바뀝니다. 예: 원본이 128×64일 때 가로를 96으로 바꾸면 세로는 48이 됩니다.
- 체인을 해제하면 가로·세로를 각각 지정할 수 있습니다. 80×32를 입력하면 결과 PNG도 정확히 80×32로 저장됩니다. 픽셀을 선명하게 유지하도록 최근접 방식으로 크기를 맞추며, 원본은 변경하지 않습니다.
- 비율 연결 상태에서 여러 이미지를 변환하면 마지막으로 수정한 가로 또는 세로 값을 기준으로 **각 원본의 비율**에 맞춥니다. 반대쪽은 정수 픽셀로 반올림하므로 비율에 작은 차이가 생길 수 있습니다.
- 출력 크기 지정을 끄면 세밀도 설정에 따른 변환 결과 해상도를 사용합니다. 가로·세로는 각각 1~8,192px, 전체 크기는 16,777,216픽셀까지 지원합니다.
- **세밀도**는 자동 또는 직접 지정(px)을 선택할 수 있습니다. 작은 숫자일수록 세밀한 부분을 살리고, 큰 숫자일수록 굵고 단순한 픽셀 표현이 됩니다. 직접 지정은 1 이상의 소수도 허용하며 이미지의 짧은 변 길이의 절반 이하여야 합니다. 출력 해상도와 별도로 적용됩니다.
- 출력 크기, 체인 연결과 세밀도 설정은 다음 실행에도 유지됩니다. 설정 범위를 벗어나면 미리보기에 안내를 표시합니다. 파일 저장 중 특정 이미지에서 오류가 발생하면 목록에 표시하고 다음 이미지를 처리합니다.
- 미리보기는 최대 800%로 확대할 수 있습니다. 큰 이미지는 미리보기만 축소하며 변환에는 원본을 사용합니다.
- 이미지는 이 컴퓨터에서 처리합니다. 이미지 파일을 서버로 업로드하지 않습니다.

## 업데이트

기본 설정에서는 앱을 시작할 때 이 저장소의 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 앱에서 알려주며, 사용자가 업데이트를 선택하면 다운로드·검증·실행파일 교체 후 다시 시작합니다. 수동으로 업데이트를 확인할 수도 있고, 시작 시 자동 확인은 끌 수 있습니다.

업데이트에는 인터넷 연결과 실행파일이 저장된 폴더의 쓰기 권한이 필요합니다. 연결이 없거나 확인에 실패해도 기존 이미지 변환 기능을 사용할 수 있습니다. 다운로드한 실행파일은 릴리스의 SHA-256 체크섬과 대조하며, 이전 실행파일은 교체 중 복구를 위해 백업합니다.

기존 1.0.0에는 업데이트 기능이 없으므로 **1.1.0 이상을 한 번 직접 받아 교체**해야 합니다. 그 이후 배포되는 새 버전부터 앱 안에서 업데이트할 수 있습니다.

설정·변환 엔진·업데이트 임시 파일은 `%LOCALAPPDATA%\PixelSnapper` 아래에 저장됩니다. 이 폴더는 처음 사용할 때 자동으로 만들어집니다.
